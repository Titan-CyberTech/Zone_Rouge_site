Prêt en deux minutes

Gratuit, sans compte. Les joueurs Windows, Mac et Linux se retrouvent dans les mêmes parties, et le jeu se met à jour tout seul. Dernière version : 3.5.2.

Windows pour ton PC

10 ou 11, 64 bits
  1. Télécharge ZoneRouge_Windows_v3.5.2.zip
  2. Dézippe-le sur le Bureau ou dans Documents, pas dans Program Files
  3. Lance ZoneRouge.exe et choisis ton pseudo
Télécharger pour Windows

Mac pour ton Mac

macOS 11+, Apple ou Intel
  1. Télécharge ZoneRouge_macOS_v3.5.2.zip
  2. Ouvre-le et glisse « Zone Rouge » dans Applications
  3. Premier lancement : Réglages Système, Confidentialité et sécurité, « Ouvrir quand même »
Télécharger pour Mac

Linux pour ton PC

64 bits, Vulkan
  1. Télécharge ZoneRouge_Linux_v3.5.2.zip
  2. Dézippe-le dans ton dossier personnel
  3. Lance ./ZoneRouge.x86_64 (si besoin chmod +x)
Télécharger pour Linux

Si Windows affiche « Windows a protégé votre ordinateur » (le jeu n'est pas signé), clique sur « Informations complémentaires » puis « Exécuter quand même ». Pourquoi cet avertissement ? Sur Mac, le jeu n'est pas signé par Apple : autorise-le une fois dans Réglages Système. Comment faire ?

Configuration

Ce qu'il te faut

Le jeu est léger : un PC récent suffit, et il tourne même sans carte graphique récente.

Windows

  • Windows 10 ou 11, 64 bits
  • Un dossier où tu peux écrire (Bureau, Documents, disque de jeux), pas « Program Files »

Mac

  • macOS 11 (Big Sur) ou plus récent
  • Mac avec puce Apple (M1 à M4) ou Mac Intel compatible Metal

Linux

  • Distribution 64 bits récente
  • Pilote graphique Vulkan conseillé (Mesa ou NVIDIA) ; sans Vulkan, le jeu passe en OpenGL
Mises à jour

Toujours à la bonne version

Pour jouer ensemble, tout le monde doit avoir la même version. Pas besoin de s'en occuper : le jeu le fait.

À chaque lancement, l'écran de chargement vérifie la dernière version publiée sur GitHub et affiche en petit ce qu'il lit. Si une version plus récente existe, le jeu montre ses nouveautés, la télécharge, vérifie sa taille et son empreinte, l'installe, puis redémarre tout seul.

Ton profil (argent, skins, statistiques) est toujours conservé. Sans connexion, le jeu démarre normalement avec la version installée.

Voir toutes les versions sur GitHub, ou lire l'historique des nouveautés.
